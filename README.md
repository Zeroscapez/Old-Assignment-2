# Assignment 2

A C# console app that prints out billing information, bill total, tip amount, and splits it based on number of guests.

## Requirements

- [.NET 10 SDK](https://dotnet.microsoft.com/download)

## How to run

```bash
git clone https://github.com/Zeroscapez/Old-Assignment-2.git
cd Assignment2
dotnet run
```

## Sample Output

```text
What is the bill total? 100
What percentage is the tip? 5
How many people are splitting the bill? 2
Tip amount: $5.00
Total bill: $105.00
Each person pays: $52.50
```
